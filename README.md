One word only: the word an agent says when it has no idea what to do — a yelp of panic, nothing attached.

> Yikes!

## How it works

`main.py` (Python 3 standard library only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: exactly one word, at most 99 characters of UTF-8 text.

```sh
python3 main.py
```
